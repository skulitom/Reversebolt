# Value-guided broad memory search — frozen v1

Freeze method, runner, fixture, relevant product source and executable hashes
before three owned native cases. Run once each in Anode; retain all failures.
No manual screenshots/game control, local model calls, process suspension or
memory writes by the evaluator/product. The fixture alone changes its own value.

Each fixture commits a 128 MiB private arena and places its numeric field at a
random aligned offset in the upper half. Reversebolt receives only normal
process/window identity and a one-MiB ordinary sampling budget. An evaluation-only
oracle records the field address and representation; neither enters discovery.
Case 0 stores float32, case 1 float64, case 2 stores float32 equal to half the
visible value (an explicit unsupported-seed representation).

Default attachment collects sixteen automatic moments with values
40,56,31,85,64,27,75,92,44,67,38,50,54,54,50,50. Select the first active OCR track
with a current reading, then issue search_number with its current scope. No
value, address, offset or representation is supplied to that command. Hold the
fixture at 50 while the product scans. Require source image provenance, ordinary
read-budget accounting, a saved selection receipt, and no selected raw bytes.

Cases 0 and 1 require the actual field to lie in a retained search window, then
sixteen automatically scheduled fresh observations of
50,56,31,85,64,27,75,92,44,67,38,50,54,54,50,50. Require the correct address in an
automatically frozen OCR check and four fresh agreeing samples. The seed is not
one of these training/validation samples. The previous batch's saved plan must
not cover the field. This proves targeted sampling of an otherwise excluded
location, not semantic or gameplay authority. No trial edit is requested.

Case 2 requires the actual encoded field to be absent from retained search
windows. Other literal copies may be found and may correlate; retain them
without treating them as the controlling field. If windows were retained, run
the same fresh sequence and require no candidate at the omitted actual field.
If the search returns no locations, retain the refusal with its read receipt.
This negative case records the representation limitation, not successful recovery.

No retries or candidate substitutions after an observed failure. Source hashes,
protocol hash, process identities, automatic-job completion, source samples,
selection windows and prospective results remain available for a post-run audit.
These are synthetic native workflow cases, not independent-game acceptance or a
statistical estimate of coverage/recall. An addressed range is not an allocation
lifetime. The eight-search, 512 MiB-per-scan, ten-second cooperative, 4096-window,
4 GiB investigation and existing archive/image limits remain in force.
