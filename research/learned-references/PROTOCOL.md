# Learned one-hop references — frozen v1

Two fresh owned WinForms processes in Anode. Before either run, freeze this
protocol, fixture, runner, product sources and packaged binary hashes. No
screenshots are manually inspected; no gameplay or UI input is used.

The fixture has one float at a random aligned offset in a private allocation.
A pointer in a separate private page identifies its base. Both addresses and
the offset are absent from product inputs. The evaluator alone reads a private
oracle. Reversebolt receives normal process/window identity, a 32 MiB budget,
and disabled local observer. Sixteen automatic captures see:
40,56,31,85,64,27,75,92,44,67,38,50,54,54,50,50.

Require a frozen numeric check with learned references. Then the evaluator moves
the allocation once, updates the pointer and frees the old object. Call the
ordinary recheck_findings command once. Candidate selection is the first
reference-derived location in the displayed track; it is not chosen by the
oracle. Require fresh values 54,54,50,50, then prepare a +3 location test. Only
after selection/preparation may the evaluator verify that its patch lies within
the new owned field. Retain old candidates and the learned offset, with before/
after pointer witnesses in all four moments.

Case 0: apply the test, require field/display 53 and a matched effect, then restore
50. Case 1: after preparation, move the object again while retaining the previous
allocation and bytes. Applying the old plan must return an error, must not call
the native write, and the fixture's current value must stay 50. (The evaluator
also reads the old four field bytes to verify they were not changed.)

No manual capture, correlation or prediction-freeze calls; no known addresses,
pointer roots, offsets, symbols or layouts supplied to discovery. No reruns or
replacement choices after an observed failure. Record missing discovery,
missing references, OCR failures, refusal and any failed assertion as failures.
This is a bounded native workflow test, not restart recovery, multi-hop pointer
support, semantic identification or independently implemented game evidence.
