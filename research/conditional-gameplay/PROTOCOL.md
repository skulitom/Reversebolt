# Observe the required activity before attempting a parameter edit

One fresh Sable development launch in Anode, with a pre-launch storage backup.
Preserve the main desktop editor and Steam session. At most four setup screenshots
and two menu keys. No measurement image is manually viewed. Freeze exact published
engine/MCP binaries, evaluation sources and installed model identity first.

Attach with automatic observation disabled. Collect fifteen Play images through
one ordinary engine observation job, at a 1,500 ms post-capture delay. These images
use the product-owned input monitor and do not read target memory. After samples
2, 4, 8 and 10, send bounded one-second D/A/D/A SendInput holds, checking the exact
selected foreground and absence of foreign input. Use a performance-counter
deadline and retain accepted transitions, actual QPC times and interruption.
Never replay uncertain input, captures or a submitted job.

After the job is authoritatively terminal, compute the shared Play evidence on
exactly these fifteen frames. If it has a valid activity source, interpret the
four selected images once using the unchanged metadata-independent activity
review. No replacement source, changed threshold, manual image judgment or retry
may manufacture an eligible observation. Lack of contrast or usable context is
a retained result and stops this experiment's analysis chain.

If valid activity context exists, use the two primary questions retained in the
separate connected-focus cleanup replay, in their original order. These remain
historical, unverified metadata from an exited process. Build a planning-only
packet with the new observed actions and a hypothetical zero-valued probe, then
run the existing test-design review once per question. Keep proposals, alternative
conditions and missing sensors explicit. Metadata event strings are not observed
events. The design packet has no live path binding or execution authority.

This experiment does not itself edit gameplay fields. Any subsequent intervention
requires a separately prepared plan with fresh discovery, resolved current paths,
durable write/read-back/restoration and an appropriate activity and measurement.
Do not use an old process path or treat a positive model design as causal proof.
After terminal work, close only owned processes, preserve storage differences and
the backup, verify the main editor, and release the Anode lease.
