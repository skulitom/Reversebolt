# Retained activity across an agent handoff

This is a development regression on saved Hyperbolica evidence, not another
native run or a test of new agent intelligence. The existing measured-contrast
replay contains a valid, ambiguous image context and two metadata questions.
The old agent-submission code created a review with `play_context: null` even
when the same observations remained current. Compare that empty-context state
with the revised shared transfer function.

Freeze product sources, dependency manifests, this protocol/evaluator, the
file-only replay executable, prior replay, original status/report and fifteen
PNG inputs before execution. Rehash images and recompute the production play
metric. The recomputed evidence must equal the prior replay; metadata questions
and their references are reused through the normal hypothesis validator.

Expected: retain the false image verdict, description, uncertainty and measured
source; attach the original local model and review identity; derive the same
four observed holds; offer the one existing eligible comparison under the new
agent review ID; keep attribution in resolved test origins and JSON roundtrip;
discard activity after a changed image reference. No model, game, editor, loader,
input or field edit is invoked. No comparison is executed.

The real app command/archive path has a separate synthetic integration test. Its
target panics on memory reads or captures. Check repeated agent submissions,
old-request replay without republication, changed-request/stale-review rejection,
changed-image exclusion, unchanged cards and archived replay after engine restart.
Core tests cover altered input samples, report, investigation, batch, failed or
missing reviews and invalid attribution. Existing comparison-store tests must
retain attribution across recovery. None of these substitutes for native-game
validation or resolves the existing Windows quarantine.
