# Candidate reads bracketing image capture

Freeze this protocol, runner, scorer, product source and binary hashes before
collecting evidence. Run one new profile each of original 2048 and Javascript
Tetris, in that order. Keep every failure. No retries, adaptive controls,
manual image inspection, source-derived layout or memory writes.

Retain the process-scope study's 16 MiB budget, optional model disabled, fixed
80 ms native key pulses every 350 ms, and three-second renderer CPU selection.
Selection is an experimental browser-specific rule, not product inference or
proof of semantic ownership. All original source and driver hashes remain
unchanged. The oracle remains separate and is never sent to Reversebolt.

Collect 12 full observations with comparison, freeze the lowest-ID active OCR
track having matches, then collect eight fresh observations without refitting.
If there are no matches, record that outcome and still collect the eight frames.
Eight fresh frames use the existing 20-frame batch limit and permit additional
evidence after uncertain timing. Do not replace a failed hypothesis with another.

The candidate product reads each unique candidate address/width before requesting
the image. The usual post-image scan supplies the other endpoint. Both reads
must retain matching raw bytes and valid ordered bounds on the same clock for
the sample to count as an agreement or contradiction. Changed or unbracketed
samples are timing-uncertain; absent post-image data remain missing. Candidate
queries and reads use the same identity, mapping checks and total byte budget.
These endpoints do not prove continuous stability or exclude display lag/ABA.

The independent scorer uses the new explicit image-request wall-clock start;
all prior 200 ms timing, geometry and stable-bracketing rules remain unchanged.
Report OCR correctness separately from the product's memory comparison outcomes.
In particular, endpoint agreement does not establish independently correct OCR.

Audit saved before/after bytes, monotonic ordering, immutable hypotheses, input
delivery and charges to the read budget. Recompute both the new assessment and
the old single-read outcomes on the same captured evidence as a descriptive
counterfactual. This does not estimate how the older product would have behaved
in a different run, and cannot recreate discarded training bytes.

These remain exposed development games. No gameplay authority, editable control,
causal understanding or withheld generalization is demonstrated by correlation.
Keep the fixed full-goal percentage at 26% pending broader verified capabilities.
