# Independent question and activity inspection

Keep the existing action replay rules and original conditional-gameplay result
unchanged. Add a default shared-engine/MCP read operation that exposes validated
metadata questions independently from the availability of checked activity or a
replay sequence. It must not prepare a trial, propose an edit value, rename a
selected alternative as its primary, change cards or call a model/target.

Generated regressions must cover ordinary supported replay, out-of-range holds,
questions excluded by the zero-value probe, separate alternatives, missing or
changed activity, stale metadata/process identities and unchanged session state.
The input limit remains 100–1000 ms; retain estimates and their original bounds.
Unknown activity does not disprove a metadata question.

After building, freeze the assessment example, sources and exact prior native
activity/evidence/status files. Replay them once without another game launch,
image model call or input. Require no executable replay, the same ambiguous
interpretation and the three original rejected durations. Audit all frozen
hashes and compare the retained bounds to the original independent audit.

Check the packaged MCP schema and its route through a fresh isolated headless
engine. No target is attached for this transport check. End only owned processes,
preserve the user's desktop editor, and activate a new preview only after the
checks succeed. Do not equate these checks with gameplay-effect validation or
independent-game generalization.
