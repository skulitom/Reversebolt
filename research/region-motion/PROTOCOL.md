# Fixed-region motion regression

The production observation reader gains one optional fixed image rectangle.
Evaluate its actual pair-measurement path with saved/generated PNGs only. No game,
new capture, target access, input, model call or field write is permitted in this
evaluation. This does not clear the existing Windows Security detection.

Before the replay, freeze the source, offline replay binary, fixture generator,
this protocol and every input hash. Use a new output folder. Generate exactly six
declared analytic cases: +8 and -8 source-pixel shifts inside a 256x144 region,
a +4 shift inside a 128x72 region, a plain region, a +48 shift beyond the normalized
search radius, and an out-of-image request. The first three expect normalized
region displacement +8, -8 and +8 respectively. Plain/out-of-range evidence must
not invent a consensus; an out-of-image request must retain an explicit error.
The unchanged background covers most of each synthetic 1024x576 image.

Also replay the fifteen retained discovery captures each from Hyperbolica and
Manifold Garden in the existing feature-motion corpus. Inspect the central half
of each image, chosen geometrically before results, not as an identified object.
These regions have no motion ground truth and are not scored for accuracy.
The original full-image measurements and activity evidence must remain exactly
equal to their retained outputs. Preserve all failures and unknowns.

Run the combined eight-case replay once with a 60-second process bound. Record
timing as a single local observation, not a benchmark. Verify original input and
frozen source/binary hashes afterward. The fixture's expected scalar difference
uses the existing product measurement; only its constructed displacement is an
analytic oracle. Do not claim held-out or independent-game acceptance.

Independent automated checks cover full-region equality with the existing
matcher, source-scale reporting, malformed rectangles, weak texture, geometry,
source hash and epoch rejection, and binding changes when the region changes.
The optional query must not change current discovery/trial decision gates or
create unnamed UI cards. A fixed rectangle does not follow an object or prove
its identity, animation, physical speed or gameplay role.
