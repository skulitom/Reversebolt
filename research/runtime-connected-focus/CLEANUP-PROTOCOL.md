# Post-measurement replay of redundant self-alternatives

The frozen connected-context review produced two proposals and rejected both
because each included its primary candidate ID in its alternatives list. Preserve
that original result unchanged. Do not rerun the model or change its prompts.

Evaluate a separate deterministic normalization: remove one exact primary ID from
an otherwise bounded, unique alternatives list, then run the unchanged strict
hypothesis validator. Do not repair names, explanations, citations, unknown IDs,
repeated distinct alternatives or oversized lists. Preserve the original batch,
every rejection and the proposal/alternative index of each removed entry.

Freeze the replay source, executable, this protocol and the original receipt hash
before running. Reconstruct the original proposals from the model stages and
require strict validation to reproduce the original batch before normalization.
Save the normalized batch as a separate artifact. New inference, target access,
inputs, images, field writes and semantic promotion are all out of scope.

Check that every accepted proposal retains its original text, citations, primary
row and distinct alternative; only the exact self-reference can disappear. This
recovers well-formed investigation questions, not verified controls. In future
metadata reviews, the shared observer retains this same cleanup record alongside
the unchanged model output and the validated batch.
