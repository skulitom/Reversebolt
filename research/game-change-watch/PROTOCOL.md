manifest before either launch. Run original 2048 then Javascript Tetris once

this evaluation addresses its missing independent-game evidence.

sampling, no optional image model, Chromium 1120x650 and unchanged upstream MIT
sources retained by the independent-games study. Serve only loopback sources;
block external page requests. Require the acquired Anode identity/lease and

Discovery and the renderer-selection rule remain those of game-change-search:
largest positive accessible renderer CPU delta over three seconds, lower PID
tie-break. Sixteen initial captures, then lowest-ID active current OCR track
with ten readable values and second highest minus second lowest >2.2. One
start_change_search gets four selection captures and an automatic fresh sixteen
capture handoff. Fit on twelve fresh moments; test on four later ones. Supply
no game value, address, representation, scale, signature or layout to discovery.
Read the selection archive if the automatic batch transition overtakes polling.

Use the prior fixed native inputs, 80 ms holds, 100 ms periods: one initial
pulse (Space starts Tetris), four pulses after discovery moments 1–11, twelve
after moment 14, otherwise none. Selection receives four after moments 1–3.
Pause and acknowledge before each burst, then resume. Verify exact HWND/PID and
session on input. Natural updates, random tiles, gravity and game-over remain
uncontrolled; do not replay uncertain input or reset games to obtain a result.

After discovery, select the lowest OCR check track with a candidate agreeing
on exactly four future moments; select its lowest qualifying candidate index.
Request current OCR +10, prepare_probe once and apply once only if prepared.
No fallback candidate or forced write. Check original process identity and
the selected candidate against the product plan. This tests one explanation.

If Written, start_change_watch requests three observations 2000 ms apart with
the exact phase/count/scope envelope. After each of the first two observations,
pause and confirm no extra observation, send the next four fixed inputs, then
resume. Save source observations, full memory persistence witnesses, sampled
input context and job receipts. The first watch observation is input-idle;
later ones follow delivered events, without assuming they changed the game.
Natural counter increments may make a useful edit differ from its original
requested number. No exact-match assertion determines whether this case runs.

Attempt guarded restore once after the watch. If bytes evolved, retain refusal
without forcing original bytes over newer state. Only if Restored, watch two
more moments with one four-input burst between them. Cleanup stops an unfinished
watch before one previously unattempted guarded restoration. Stopping does not
itself restore. Close only owned test processes and release Anode afterward.

The independent oracle uses CDP DOM text/box reads for score/best (2048) or
score/rows (Tetris); numbers are parsed outside the renderer. It reads no numeric
game variables or board/piece state. Generic viewport geometry and trusted key
listeners remain instrumentation and can add observer objects/overhead. Inputs
must match trusted browser events. No source-derived game layout enters product.

Discovery scoring retains the 200 ms oracle request/gap exclusion and spatial
association. Baseline, immediate edit and restoration use complete RPC intervals.
Watch intervals conservatively span the product observation's wall-clock start
through the evaluator's receipt after persistence. Bracket each with completed
and beginning oracle requests; require unchanged counter value, box, viewport,
supported geometry and bounded gaps. Otherwise mark unscorable. Equal sampled
text cannot exclude intermediate changes, rendering delay or ABA. No manual
image viewing or manual gameplay. Hash every saved source image post-run.

Separate observed response from causation: a matching displayed number, evolving
memory or later increase alone cannot establish internal-score authority. There
is no paired counterfactual here; fixed inputs still permit random and natural
changes. Byte restoration is not full game rollback. Report workflow completion,
candidate agreement, effect outcomes and refusal separately. Retain progress at
31% unless independent capability evidence justifies new milestone credit.
