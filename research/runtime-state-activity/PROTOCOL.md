# Current-state activity with independent image checks

Evaluate the new explicit current_state type selector on a fresh native Sable
catalog. This remains a known-game development test. No game-specific names,
offsets, saved field choices, source layouts or manual field selection enter it.

Freeze sources, exact previously tested native reader/loader, analysis binaries,
current-state selector, published capture engine/MCP and installed model identity.
Back up storage before the owned Anode launch. Preserve the user's desktop editor.
At most four setup screenshots and two menu keys; no measurement image is viewed
manually. No gameplay fields are written and no semantic control is published.

Use one bounded discovery page and the unchanged current-state selection prompt,
with at most 24 requests of at most 12,000 bytes. Stop before naming proposals.
Feed the complete selection into the unchanged enclosing-role sampler: 128 paths,
at most eight native batches in plan order, retaining all omissions. No reranking
after observing values or pictures. Record the plan hash before sending input.

Each batch keeps the fourteen-sample QQDQQAQQDQQAQQ protocol and exact four-repeat
association rules. Holds last at most five seconds using a performance-counter
deadline and SendInput scan-code packets, polling selected foreground/key state
every five milliseconds. Release on conflict or completion; never replay input.
Native reads occur inside holds. Quiet samples wait at least 250 ms before the
native call, whose observed preparation latency remains part of the timing.

After samples 0, 1, 2, 4, 5 and 6, capture the selected window through the unchanged
product Play API after any held key has been released. Six images per batch fit
the existing 48-image limit. The first two images show a quiet interval, the third
follows the first D hold, the fourth follows both intervening quiet samples, the
fifth follows the first A hold, and the sixth follows its next quiet sample.
These image intervals differ in length; report their actual timing. Image and
memory samples are sequential, not atomic. The second D/A repeats have native
input coverage but no independent image pair. Do not silently extend this claim.

Retain per-batch image hashes, compositor clocks, pixel differences and sparse
patch matches. Direct captures have no product-owned input monitor; their unknown
classifications must remain unchanged. Associate the external sequence only in
this diagnostic record. Rendered changes are evidence of response, not identified
actors, input semantics, causality, physical speed or editing authority. No image
threshold may retune the frozen scalar analysis. Post-release change remains
visible; it is not assumed to be idle gameplay merely because keys are released.

After terminal completion and helper unload, close only owned processes, preserve
save differences and the backup, verify the main editor, and release Anode. Retain
failures, partial coverage and any uncertain operation without restarting it.
