# Explicit location-probe integration

Freeze source, runner, protocol and product hashes before testing. Run two fresh
owned WinForms fixtures, first with the lower-address source and then the upper-
address source. Both fields receive the same fixed training values. Only the
source drives the painted Quantity; the other is a persistent unused copy.
Offsets are randomized inside one private page. Neither offsets nor the oracle
are supplied to Reversebolt. This is a controlled integration, not an independent
game or a claim of gameplay authority.

Use ordinary MCP attachment with automatic observation/model disabled and a
32 MiB budget. Capture twelve fixed varied values, compare, freeze the lowest-ID
active OCR series having matches, then capture 54,54,50,50. Attempt ordinary
preparation to retain its agreement/abstention outcome. Select candidate index
zero for an explicit location probe to 53. Never replace a failed selection
with another candidate or rerun a failed case.

Preserve all rival hypotheses and conditional predictions. Before application,
the evaluator checks that the entire proposed patch lies within one of the
fixture's two owned four-byte fields. This is a containment check only; it may
refuse the selected patch but cannot select an address, revise a proposal or
provide a layout to the engine. Record an abstention if no plan qualifies.

Case one uses MCP to apply, observe, replay the completed application (which
must not write twice), restore, and observe restoration. Case two prepares with
MCP and uses accessible desktop controls to apply and restore the exact plan;
the runner waits for those shared journal outcomes. No manually inspected
screenshots are needed. Unknown or conflicting writes are never retried or
force-restored. Close only the owned fixtures/engines at the end.

Evaluate the observed primary value, both independent oracle bytes, the recorded
alternative fits, complete-byte restoration and passive-check invalidation.
Report actual selection and outcomes even if both cases select the same role
or abstain. A response is evidence of influence in this fixture, not proof of
general causal authority, complete recovery or automatic semantic labeling.
