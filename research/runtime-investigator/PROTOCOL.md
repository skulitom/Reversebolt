# Integrated runtime investigator on a real game

Previous goal turn: progress. It connected externally supplied hypotheses and
their alternatives to durable engine comparisons. This run tests the unchanged
shared workflow in an actual game, beyond the owned fixture.

Freeze product/evaluator identities and this protocol before launch. Use Manifold
Garden's existing evaluator slot 3; preserve pre-existing slots 1/2. Back up saves
and record changed files without silently restoring user progress. No source,
disassembly, offset or game-specific discovery profile enters the product.

Attach to fresh gameplay with the installed local model and automatic runtime
discovery. Select the first accepted hypothesis, in model order, with two distinct
floating-point fields of the same declaring type, each currently finite, positive
and at most 20. Use its primary and first eligible alternative. Resolve all observed
paths for each field; require 1–4 untruncated paths, identical fresh bytes and one
observed field address before selecting a retained hypothesis path. Otherwise
decline that hypothesis; do not replace the policy with a remembered field name.

For each candidate, use the shared prepare/observe/edit/restore comparison APIs.
Record the original hypothesis provenance. Collect a stationary pair and four
alternating D/A 200 ms holds per condition, settling 350 ms before captures. These
inputs come from the earlier exploratory walking test, not a newly learned action
policy. At most 24 movement holds and 36 measurement images for two candidates.
Input and game focus are checked in Anode; all measurement images are evaluated
automatically by the existing engine metric. Review only setup screenshots needed
to load the evaluator save. No camera actions during measurement.

The only intervention is zero, through the existing <=20 delta guarded path,
followed by its exact durable Undo. A complete strong baseline is required before
writing. Do not force a drifted reference, repeat an uncertain input/write, or
freeze a value. Attempt recovery of a confirmed write on later test failure using
the original trial. Keep refusals, missing capture/input evidence and inconclusive
results. Do not retry or adjust thresholds to manufacture a positive result.

Success here means the shared investigator can execute and retain an actual-game
comparison, including failed hypotheses and recovery. It does not establish a
semantic name, exact world speed, unattended input planning, persistent identity,
generalization, or the full product goal. This game and input plan were inspected
earlier, so this is exploratory integration evaluation, not held-out testing.

Close only owned game/headless/MCP processes and release Anode. Verify saved
receipts, helper unloading, pause behavior and preservation of user save slots.
