# Retained trial displacement comparison

Evaluate the production `trial_motion::analyze` path without new game execution,
captures, model calls, input or writes. This is a development regression, not an
independent-game evaluation or evidence that Windows Security has cleared the app.

The source records are all three saved tests from `planned-input-v1/case/data`.
They belong to OwnedPathFixture, including the record whose raw field is named
WalkSpeed. Do not label them as Manifold Garden or treat the field name as truth.
Use the complete 18-image comparison and both interrupted records; retain all
outcomes. The existing scalar assessment must remain exactly unchanged.

Freeze source files, the offline example executable, input identities and this
protocol before running. Run each record once, with a new output path and a
30-second process bound. Rehash all original input files afterward. Never open
the source through the mutable runtime-test store or overwrite its records.

The shared policy compares the same action index across the three conditions.
Each of fifteen possible image pairs requires verified bytes and dimensions;
input witnesses are recomputed from their checksum-bound sampling windows. Global
chronology and monitor generation must agree. Every pair needs the feature
matcher's distributed consensus; absence is not zero. Idle displacement must be
within one normalized pixel per axis and each baseline action at least two pixels
on one axis. A change is at least three pixels on one axis, agreement is at most
one pixel per axis, and the two-pixel gap remains inconclusive. All four actions
must differ and return to produce the descriptive change-and-return pattern.
Thresholds are heuristics. This does not establish physical speed, a causal edit,
actor identity, restored gameplay state or a verified semantic control.

Automated tests separately cover known image shifts in alternating directions,
the actual command/store/restart path, source image and input corruption, partial
evidence, insufficient support, idle movement, wrong input, threshold gaps and
failure to return. These synthetic sequences have no gameplay effect or native
edit authority. The app's existing trial assessment is never rewritten.
